# Birthday-Ruizhu

A private, zero-cost birthday microsite prototype.

## Current state

- Visual system only
- All personal copy intentionally left blank
- All photos intentionally left blank
- Mobile-first responsive layout
- Editorial cream / burgundy / deep-brown palette
- Traditional Chinese serif + handwritten web-font stack
- Scroll reveal interactions
- Sections prepared for hero, editorial memory, filmstrip gallery, quote, timeline, reasons, letter, and locked future chapter

## Editing later

Replace photo slots with `<img>` elements and fill only the content areas you want to use. The initial visual preview deliberately contains no personal message or photo.

## Run locally

Open `index.html` directly, or serve the directory with any static HTTP server.
